WhiteHat School 4기 네트워크 보안 과제에서 C와 libpcap으로 TCP 패킷을 읽었다. 패킷에서 Ethernet, IPv4, TCP 헤더를 차례로 확인하고 포트 80의 페이로드 일부를 출력하는 실습이다.

## 헤더 길이를 읽어서 다음 위치로 이동하기

Ethernet 헤더의 유형 필드를 읽어 IPv4 패킷만 고른 뒤 IP 헤더의 프로토콜 값으로 TCP인지 판별한다. 그다음 IPv4의 IHL과 TCP의 Data Offset을 읽어 각각의 헤더 길이를 구한다. 두 필드의 값에 각각 4를 곱하면 헤더 길이를 바이트 단위로 구할 수 있다. Ethernet 헤더 길이에 이 두 길이를 더하면 옵션이 있는 헤더에서도 페이로드 시작 위치를 계산할 수 있다.

과제 프로그램은 출발지와 목적지의 MAC·IP 주소와 TCP 포트를 출력한다. 포트 80인 패킷의 페이로드는 최대 512바이트까지 보여준다. 이 출력은 개별 패킷의 미리보기다. 여러 TCP 세그먼트에 나뉘어 전송된 HTTP 메시지 전체를 확인하려면 세그먼트를 재조립해야 한다.

## 샘플 파일로 검증하기

저장소에 포함된 샘플 PCAP을 사용하면 같은 입력으로 반복 실행할 수 있다. 실시간 캡처보다 실행 결과를 비교하기 쉬워서 오프셋과 출력 형식을 점검하기에 좋다. 다음에는 IP나 TCP 옵션이 있는 패킷과 일부만 캡처된 패킷도 추가해 계산한 위치가 실제 캡처 길이를 넘지 않는지 확인하고 싶다.
