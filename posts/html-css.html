HTML과 CSS로 첫 블로그 만들기

수업에서 배운 내용으로 만들기

인터넷활용 수업의 예제를 바탕으로 블로그를 만들었다. HTML로 내용을 작성하고, CSS로 색과 간격을 정했다.

사용한 내용

  • 2주차: HTML 기본 구조와 외부 CSS 연결
  • 3주차: 제목, 문단, 목록, 링크와 구조화 태그
  • 4주차: 태그 선택자, 클래스 선택자와 상태 선택자
  • 6주차: 글꼴, 배경색, 테두리, margin과 padding
  • 8주차: float 배치와 미디어 쿼리

화면 구성

위쪽에는 자기소개, 왼쪽에는 카테고리, 오른쪽에는 공부 기록을 배치했다. 화면이 좁아지면 왼쪽 메뉴와 글 목록이 위아래로 나타나도록 했다.

앞으로 할 일

새로운 내용을 배울 때마다 글을 추가하며 블로그도 조금씩 다듬어 가려고 한다.
