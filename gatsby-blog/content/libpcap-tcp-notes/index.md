WhiteHat School 4기 네트워크 보안 과제에서 C와 libpcap으로 TCP 패킷을 읽었다. 패킷에서 Ethernet, IPv4, TCP 헤더를 차례로 확인하고, 포트 80의 페이로드 일부를 출력하는 실습이다.

## 헤더 길이를 읽어서 다음 위치로 이동하기

먼저 Ethernet의 유형을 확인해 IPv4인 패킷만 선택하고, IP의 프로토콜 값으로 TCP인지 판별한다. 그다음 IPv4의 IHL과 TCP의 Data Offset을 읽어 각각의 헤더 길이를 구한다. 두 필드는 4바이트 단위이므로 바이트 길이로 환산해야 한다. 이 길이를 더해 페이로드 시작 위치를 계산하면 옵션이 있는 헤더에도 같은 원리를 적용할 수 있다.

과제 프로그램은 출발지와 목적지의 MAC·IP 주소와 TCP 포트를 출력한다. 포트 80인 패킷의 페이로드는 최대 512바이트까지 보여준다. 이 출력은 개별 패킷의 미리보기이므로 여러 TCP 세그먼트에 걸친 HTTP 메시지 전체를 재조립한 결과와 구분해야 한다.

## 샘플 파일로 검증하기

저장소에 포함된 샘플 PCAP을 사용하면 같은 입력으로 반복 실행할 수 있다. 실시간 캡처보다 결과 비교가 쉬워, 오프셋과 출력 형식을 점검할 때 유용하다. 다음에는 IP나 TCP 옵션이 있는 패킷과 짧게 잘린 패킷을 추가해, 계산한 위치가 실제 캡처 길이를 넘지 않는지까지 확인하고 싶다.
