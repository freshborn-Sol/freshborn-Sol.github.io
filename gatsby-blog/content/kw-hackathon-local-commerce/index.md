2026년 10월 광운대학교 KW 해커톤 상권 활성화 트랙에서 팀 프로젝트에 참여했다. 포트폴리오에는 프로젝트를 ‘월Gather’로 기록했고, 팀 저장소의 중간발표 자료는 ‘월계 식당 패스’라는 이름을 사용한다.

## 학생과 점포가 겪는 문제

제휴 혜택이 있어도 학생은 자신이 해당되는지 확인하기 어렵고, 점포는 손님이 적은 시간에 혜택을 알릴 통로가 필요하다. 팀은 학생이 소속에 맞는 제휴를 찾아보고, 점포는 시간대별 할인을 등록하는 흐름을 기획했다. 식당 방문을 이어갈 수 있도록 QR 스탬프와 방문 기록도 구상했다.

## 중간발표에서 준비한 것

공개 저장소에는 클릭형 웹 프로토타입, 데이터베이스 설계, API 명세 초안, 시연 영상이 남아 있다. 화면에서 사용 흐름을 보여주는 작업과, 실제 사용자 데이터와 알림을 연결하는 개발 작업은 범위가 다르다. 중간발표 자료에 적힌 예정 기능을 모두 구현했다고 보기보다는, 구현한 흐름과 이후 검증할 항목을 구분하는 편이 정확하다.

해커톤에서 제안의 범위를 좁힐 때는 기능 개수보다 처음 사용하는 사람이 한 가지 목적을 끝까지 달성할 수 있는지가 중요하다고 느꼈다. 다음에는 학생의 혜택 확인부터 점포의 혜택 등록까지 한 흐름을 먼저 시연하고, 사용자가 막힌 지점을 기록해 개선 우선순위를 정하고 싶다.
